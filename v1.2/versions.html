Versions

Cronologia de les edicions, actualitzacions i ampliacions de l’estudi.

Públic i Prestigi és un estudi viu. Cada edició anual incorpora un any més a la sèrie històrica: la v1 cobreix 1965–2025, la v2 ampliarà l’estudi fins a 1965–2026, i així successivament; incorporant les possibles noves entrades al Top 100 històric d’espectadors i els nous reconeixements en festivals i acadèmies. És l’actualització anual de base del projecte. Les versions intermèdies (v1.1, v1.2...) introdueixen durant l’any nous capítols d’anàlisi, ampliacions o revisions de l’estudi.

Les versions publicades queden accessibles en aquest historial. Aquí se’n resumeixen els principals canvis, els posts de Substack n’expliquen el context i les implicacions.
