# Dades de Públic i Prestigi — v1.2

Aquesta carpeta conté les dades que alimenten les taules, els gràfics i les visualitzacions de l'estudi. La versió 1.2 abasta el període 1965–2025.

## Arxius principals

- `films.json`: pel·lícules del Top 100 i pel·lícules de context, amb els indicadors d'audiència.
- `market.json`: sèrie anual del mercat cinematogràfic espanyol i població de referència.
- `population.json`: sèrie demogràfica auxiliar per contrastar els càlculs.
- `festivals.json` i `fora-competicio.json`: dades dels festivals i seccions complementàries.
- `oscar.json` i `efa.json`: reconeixements dels Oscar i els European Film Awards.
- `metadata.json`: metadades de la versió.

Hi ha arxius complementaris o històrics que poden conservar valors antics i que no són necessàriament les fonts operatives de les visualitzacions actuals.

## Fonts i criteris

Les dades de públic parteixen dels anuaris de l'ICAA; les sèries de mercat i població es documenten amb fonts ministerials, INE i les reconstruccions indicades a l'estudi. Els reconeixements provenen dels organismes i festivals corresponents.

Per a les definicions, les excepcions, els criteris de selecció i les fonts precises, consulteu [Fonts i eines](https://publiciprestigi.com/part-i.html#fonts) i les [notes metodològiques](https://publiciprestigi.com/notes.html). Les dades es publiquen en el context d'aquests criteris; no s'han d'interpretar al marge de les notes i limitacions de l'estudi.
